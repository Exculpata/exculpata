# Client discussion and consent template

**Lawyer completion instructions:** Everything in square brackets is a prompt to
replace after investigation and a client conversation. Do not send this unfinished
form, preselect consent, or treat a signature as automatic compliance. All
identifiers below are synthetic placeholders. Store the completed document in the
appropriate private client file, never in this public repository.

First complete the [vetting checklist](VENDOR_VETTING_CHECKLIST.md) and verify the
actual deployment against [data handling](DATA_HANDLING.md). Those documents
contain the implementation evidence; this template makes no deployment promises.
Decide separately whether communication and informed consent are required for the
specific use. [ABA 512, pp. 6–8][aba] and [NYC 2024-5, pp. 2–3 and 6–7][nyc]
distinguish confidentiality-risk consent from broader communication duties.
Use the current rules and orders applicable to this client; a generic engagement
clause is not a substitute for a meaningful explanation of material risks.
